MemOS 长期语义记忆
GeneralTextMemory — Qdrant + Redis
读取路径 (orchestrator)
1. LLM 生成语义查询 (2-3 条)
2. topics cube 搜索 → historical_topics
3. feedback cube 搜索 → prior_corrections
S3: 查询失败 → 流水中断
写入路径 (sync worker)
1. output_composer 入队 sync_jobs
2. winnow memos flush 处理
3. 写入 topics cube (每日快照)
4. 写入 feedback cube (修正记录)
Cube 结构
{group_id}:topics
{group_id}:feedback
去重: get_all → delete → 重新写入
