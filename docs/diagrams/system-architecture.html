Pipeline — Data Flow (6 Steps)
STEP 01 Fetch pipeline/weflow_client.py
Input
WeFlow API GET /api/v1/messages
Params: talker, start/end, media=1, image=1
Processing
Type mapping 0:text, 1:image, 4:file, 49:appmsg
Filter system (type=80)
appmsg XML parse → readable text
file/link/reply XML parse
Output
Cleaned message list with fields:
server_id, sender, msg_type, content, media_url, media_local_path, raw_content

ISSUE: media_local_path always empty
▼
STEP 02 Ingest pipeline/ingest.py
Input
Cleaned message list
Target date YYYYMMDD
Processing
Prompt injection check sandbox.py
INSERT OR REPLACE by serverID
Sanitize flag + pattern logging
Output
→ raw_messages table
Returns: {total, new, updated, sanitized, skipped}
▼
STEP 03 Context Assembly pipeline/context.py
Input
Raw messages from raw_messages
Optional: image descriptions dict
Processing
Sort by timestamp
Format: [HH:MM] sender: content
Chunk at 128k tokens
Inject role-boundary prompt
XML wrap each message
Output
→ parsed_contexts table
Context ID: {date}-{seq}
ISSUE: only 1 row exists
▼

Known Issues — P0 Iteration 1 Blockers
ISSUE-01 · Critical
73% 数据为 Mock 假数据
337 条消息中 247 条来自 MockWeFlowClient。9 天数据 100% 为假数据，仅 20260429 有完整真实数据 (49 条)。
-- 判定: mock = serverID LIKE '%msg_%' SELECT date, COUNT(*), SUM(CASE WHEN serverID LIKE '%msg_%' THEN 1 ELSE 0 END) as mock FROM raw_messages GROUP BY date;
ISSUE-02 · Critical
图片分析管道从未触发
image_analyzer.py 已实现 Vision API + MCP 双模式，但 analyze_images_batch() 依赖 media_local_path，该字段在所有 49 条 image 消息中为空。
-- 判定: media_local_path 全部为空 SELECT serverID, json_extract(raw_json,'$.mediaLocalPath') FROM raw_messages WHERE msg_type = 'image' LIMIT 5;
ISSUE-03 · Medium
PDF 被标记为 [音乐]
type=other 的消息中 content=[音乐] 网络环境配置说明.pdf。当前代码无添加 [音乐] 前缀的逻辑，问题来自上游或旧数据格式。
-- 查看异常消息 SELECT serverID, content, msg_type FROM raw_messages WHERE content LIKE '%音乐%';
ISSUE-04 · Low
Layer 2/3 数据覆盖不足
parsed_contexts 仅 1 行，topic_summaries 为 0 行。Layer 2/3 需 graph 运行才生成，仅 ingest 不触发。
-- 覆盖率检查 SELECT 'raw' as layer, COUNT(*) as cnt FROM raw_messages UNION ALL SELECT 'ctx', COUNT(*) FROM parsed_contexts UNION ALL SELECT 'topic', COUNT(*) FROM topic_summaries;
